# Pariscope for Linux (Velocity Tech)

Install (Debian, Ubuntu, Fedora, Arch):

    curl -fsSL https://raw.githubusercontent.com/SINOBI71/pariscope-linux/main/install.sh | sudo bash

Then open http://localhost:4000 or use the Pariscope icon in your applications menu.

Commands: pariscope {start|stop|restart|status|logs|open|update|uninstall}
